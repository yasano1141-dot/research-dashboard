# 過去レポートの例

このフォルダには、過去に生成したレポートのHTMLサンプルが格納されている。
新規レポート生成時のフォーマット・分量・スタイルのリファレンスとして使う。

## ファイル一覧

### 月曜（老年医学・健康寿命）
- `example_monday_regular.html` — 通常レポート（10論文均等解説）
- `example_monday_detail.html` — 詳細分析レポート（Top 3 × 7セクション）

### 火曜（身体活動・運動疫学）
- `example_tuesday_regular.html` — 通常レポート
- `example_tuesday_detail.html` — 詳細分析レポート

## 注意

これらのサンプルは過去仕様のため、以下の差異がある：

### `example_monday_*` (2026/04/27)
- ✅ お気に入りチェックボックス機能あり
- ❌ 「オリジナリティ」「新発見項目」セクションは未実装（旧仕様）

### `example_tuesday_*` (2026/04/28)
- ✅ お気に入りチェックボックス機能あり
- ❌ 「オリジナリティ」「新発見項目」セクションは未実装（旧仕様）

## 新仕様での生成

新しく生成するレポートは、以下を **必ず追加** する：

1. **オリジナリティ** セクション（独立、紫系カラー `.section.originality`）
2. **新発見項目** セクション（独立、緑系カラー `.section.discovery`）

詳細は `references/output-spec-regular.md` を参照。
