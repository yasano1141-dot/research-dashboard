## ファイル命名規則

### 通常レポート（バージョンA）

```
{YYYYMMDD}_{テーマ名}.html
{YYYYMMDD}_{テーマ名}.docx
```

例：
- `20260427_老年医学・健康寿命.html`
- `20260428_身体活動・運動疫学.html`
- `20260429_筋質・体組成.html`

### 詳細分析レポート（バージョンB）

```
{YYYYMMDD}_{テーマ名}_詳細分析.html
{YYYYMMDD}_{テーマ名}_詳細分析.docx
```

例：
- `20260427_老年医学・健康寿命_詳細分析.html`
- `20260428_身体活動・運動疫学_詳細分析.docx`

## テーマ名のマッピング

ファイル名に使うテーマ名（中黒・記号含む）：

| 曜日 | フォルダ名 | ファイル内テーマ名 |
|------|-----------|------------------|
| 月 | `月曜日_老年医学・健康寿命` | `老年医学・健康寿命` |
| 火 | `火曜日_身体活動・運動疫学` | `身体活動・運動疫学` |
| 水 | `水曜日_筋質・体組成` | `筋質・体組成` |
| 木 | `木曜日_脳・認知` | `脳・認知` または `認知機能・脳研究` |
| 金 | `金曜日_疫学方法論` | `疫学方法論` |
| 土 | `土曜日_AI・データ科学` | `AI・データ科学` |
| 日 | `日曜日_遺伝子・オミクス` | `遺伝子・オミクス` |

## 日付フォーマット

- ファイル名: `YYYYMMDD`（例：`20260428`）
- メール件名: `YYYY年M月D日（曜日）`（例：`2026年4月28日（火）`）
- レポート本文: `YYYY年MM月DD日（曜日曜日）`（例：`2026年4月28日（火曜日）`）

## bashで日付取得

```bash
# YYYYMMDD 形式
date +%Y%m%d
# 例: 20260428

# YYYY年M月D日（曜日）
LANG=ja_JP.UTF-8 date "+%Y年%-m月%-d日（%a）" | sed -e 's/Mon/月/' -e 's/Tue/火/' -e 's/Wed/水/' -e 's/Thu/木/' -e 's/Fri/金/' -e 's/Sat/土/' -e 's/Sun/日/'

# 曜日番号（0=日, 1=月, ..., 6=土）
date +%w
```

## 既存ファイル衝突時の処理

同じ日に再実行する場合：
1. デフォルトでは上書きしない（一度確認）
2. ユーザーがスケジュールタスクから自動実行している場合は上書きOK
3. バックアップが必要なら `_old` サフィックス付きで残す
