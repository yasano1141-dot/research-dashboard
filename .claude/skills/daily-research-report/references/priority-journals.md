## 検索戦略

### WebSearch クエリの組み立て方

**基本パターン：**
```
{テーマキーワード} 2026 cohort meta-analysis {特定ジャーナル}
{テーマキーワード} latest 2026 mortality
{テーマキーワード} recent UK Biobank {テーマ}
```

**最新性の担保：**
- 必ず「2026」または「latest」「recent」を含める
- 1〜2本は「2026年1〜4月」公開の論文を選ぶ
- preprint（medRxiv、bioRxiv）は方法論論文では許容、実証研究では査読済を優先

### 研究デザイン優先順位

1. **メタ解析・システマティックレビュー** — 最高
2. **大規模前向きコホート（n>10,000）** — UK Biobank, NHANES, NHS, JAGES, TMM, Framingham等
3. **因果推論研究** — Target trial emulation, MR, g-formula応用
4. **方法論論文** — 新しい統計手法、報告ガイドライン
5. **大規模RCT** — n>1,000
6. 中規模コホート / 中規模RCT
7. （除外）小規模研究 n<500、症例報告、基礎研究のみ、レビュー（メタ解析以外）

### 除外基準

- 症例報告（case report / case series）
- 基礎研究のみ（in vitro, animal model）
- サンプルサイズが小さい（n<500、ただし方法論論文は除く）
- 査読なしの古いプレプリント（2024年以前のもの）
- 撤回された論文（retracted）
