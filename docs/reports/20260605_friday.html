Optimal blood pressure target in patients with uncomplicated hypertension: a target trial emulation study

Zhang R, Lam ICH, Emilsson L, Sun F, Zhan S, Yiu KH, Fong DYT, Yu EYT, Chui CSL, Chan EWY, Wong ICK, Lam CLK, Danaei G, Wan EYF · Nature Communications (IF=15.7), 2026年（June 5 2026） · Target trial emulation。Hong Kong の territory-wide public healthcare database を用いた retrospective cohort（n=118,271、uncomplicated hypertension）で intensive（<130/80 mmHg）vs standard（130-140/80-90 mmHg）BP target の比較

▎一言要約
Intensive blood pressure（BP）management の RCT エビデンス（SPRINT 等）が確立しているにもかかわらず、primary care における real-world での効果と安全性、および臨床ガイドラインの BP target の選択は依然として議論が続いている。本論文は Hong Kong の territory-wide public healthcare database を用いた target trial emulation（TTE）で、uncomplicated hypertension の患者 118,271 名を対象に intensive（<130/80 mmHg）と standard（130-140/80-90 mmHg）の2つの BP target を比較。Intensive target 群は hypertension-related complications と全原因死亡 の risk 低下を示し、serious adverse events の significant な増加は認められなかった。RCT の効果が primary care setting でも replicate されることを示し、BP target<130/80 mmHg を成人 hypertension の primary care 臨床ガイドラインに採用する evidence を提供する 2026 年 6 月 5 日公刊の Nature Communications 最新論文。
▎研究概要
**背景**：intensive BP management の臨床的 benefit は SPRINT・ACCORD など RCT で実証されてきたが、primary care setting での real-world 採用は限定的で、その理由として RCT 集団の選択バイアス（compliance high、monitoring intensive）と real-world での generalize 可能性への懸念がある。臨床ガイドラインも intensive vs standard BP target の選択に揺れがあり、real-world エビデンスが意思決定に必要だった。**方法**：本研究は Hong Kong Hospital Authority の territory-wide public healthcare database を用い、uncomplicated hypertension の成人患者 118,271 名を対象とした target trial emulation を実装。Treatment は (1) intensive BP target（<130/80 mmHg）、(2) standard BP target（130-140/80-90 mmHg）。Hypothetical RCT を明示的に設計し、eligibility・time zero・treatment assignment・follow-up を emulate。Cloning, censoring, weighting 戦略で per-protocol effect を推定。アウトカム は hypertension-related complications（心筋梗塞・脳卒中・心不全・腎不全）、全原因死亡、および serious adverse events（hypotension・syncope・腎機能悪化・electrolyte 異常）。**結果**：Intensive BP target 群は hypertension-related complications と全原因死亡 の risk 低下を示し、serious adverse events の significant な増加は認められなかった。RCT で示された intensive BP management の benefit が、primary care の real-world setting でも replicate されることを実証。**結論**：本論文は intensive BP target（<130/80 mmHg）の primary care setting での効果と安全性を real-world で実証し、adult hypertension の臨床ガイドラインで BP target<130/80 mmHg を採用する evidence を提供。TTE framework により observational data から RCT エビデンスへの translational gap を埋めた好例で、territory-wide healthcare database の利点（網羅性・長期追跡）と TTE 方法論の組合せを最大限活用した 2026 年 6 月 5 日公刊の Nature Communications 最新論文。
▎重要な点
Intensive BP management の臨床ガイドライン採用に向けた real-world evidence として直接的に機能する論文。Territory-wide healthcare database 11.8万人規模での TTE 実装は方法論の scalability を示し、SPRINT・ACCORD の RCT エビデンスを primary care setting に translate する 2026 年最新エビデンス。TTE による observational data から causal inference を導く現代的方法論の応用 model として、real-world data 解析の reporting standard 向上に寄与。
▎オリジナリティ（独自性）
RCT で確立された intensive BP target の benefit を、real-world primary care setting で TTE framework により replicate した点が新規。Hong Kong の territory-wide public healthcare database の網羅性（11.8万人 uncomplicated hypertension）と TTE の rigour を組み合わせ、cloning, censoring, weighting で per-protocol effect を厳密推定。Adverse events も同時評価し、benefit-risk profile を一括提示。
▎新発見項目（新しく分かったこと）
①Hong Kong territory-wide public healthcare database を活用した TTE 実装で uncomplicated hypertension 11.8万人を解析、
②intensive BP target（<130/80 mmHg）vs standard BP target（130-140/80-90 mmHg）の2群を hypothetical RCT として明示的に emulate、
③intensive BP target 群で hypertension-related complications（心筋梗塞・脳卒中・心不全・腎不全）の risk 低下を観察、
④intensive BP target 群で全原因死亡 の risk 低下を観察、
⑤serious adverse events（hypotension・syncope・腎機能悪化・electrolyte 異常）の significant な増加は認められず、benefit-risk profile が favorable、
⑥cloning, censoring, weighting 戦略で per-protocol effect を厳密推定、
⑦SPRINT・ACCORD の RCT エビデンスが primary care setting の real-world で replicate されることを実証、
⑧territory-wide healthcare database の網羅性により selection バイアス を最小化、
⑨TTE framework で eligibility・time zero・treatment assignment・follow-up を明示し バイアス を制御、
⑩成人 hypertension の臨床ガイドラインで BP target<130/80 mmHg を採用する evidence を提供。
▎方法論評価
Hong Kong の territory-wide public healthcare database（Hospital Authority データ）を用い、uncomplicated hypertension 11.8万人を対象とした TTE は サンプルサイズ と網羅性の両面で方法論的金字塔。Hypothetical RCT の明示的設計、cloning, censoring, weighting による per-protocol effect 推定、benefit-risk profile の一括評価で TTE の rigorous な実装を達成。Limitation として、本研究は Hong Kong の単一 healthcare system に依存しており、他地域 healthcare system への一般化可能性は別途検証が必要。
▎限界
本研究は Hong Kong の territory-wide healthcare database に依存しており、他地域 healthcare system や他の人種・民族集団への一般化可能性は別途検証が必要。BP measurement の頻度や手技は real-world で variability があり、measurement error が残る。Comorbidities や medication adherence の time-varying nature は cloning, censoring, weighting で処理されるが、未測定 交絡 の影響は完全には排除できない。本紹介はアブストラクト読解に基づき、本文の具体的 効果サイズ や追加 感度分析 の詳細は本文確認が必要。

#2 疫学方法論

Reducing unmeasured confounding from non-compliance with randomization in surgical RCTs: a simulation study

Lu Z, Li W, Wang M, Huang L, Chen F · BMC Medical Research Methodology (IF=3.4), 2026年（June 5 2026） · シミュレーション方法論研究。lumbar discectomy trial の現実的 parameter（crossover rate 10-40%）で intention-to-treat（ITT）、per-protocol（PP）、as-treated（AT）、instrumental variable（IV）、difference-in-differences（DiD）、double negative control（DNC）を比較

▎一言要約
Surgical RCT における randomization からの non-compliance（治療群間 crossover、protocol 違反）は pervasive で、これに起因する 未測定 交絡 が causal inference の妥当性を損なう。既存手法（intention-to-treat、per-protocol、as-treated、instrumental variable）はいずれも crossover が大きい場面で著しい限界を持ち、surgical trial では特に問題となる。本論文は lumbar discectomy trial の現実的 parameter を用いた シミュレーション で、negative control 系手法（difference-in-differences と double negative control, DNC）を従来の4手法と比較。Crossover rate 10-40% の全範囲で DNC は最小 バイアス と near-nominal coverage を達成し、n=100・40% crossover で IV 対比 MSE を 90% 以上削減、coverage probability 97.7% を維持。Surgical RCT における non-compliance 由来 交絡 への新しい methodological best practice を 2026 年 6 月 5 日公刊の最新シミュレーション研究として確立。
▎研究概要
**背景**：surgical RCT における non-compliance（randomization 後の crossover、protocol 違反、surgical conversion）は pervasive で、観察される治療効果が intention に対する効果なのか actual treatment への効果なのかを曖昧にする。Intention-to-treat（ITT）解析は randomization の利点を保持するが治療効果を dilute、per-protocol（PP）と as-treated（AT）解析は治療効果を直接推定するが selection バイアス を導入、instrumental variable（IV）解析は monotonicity と exclusion restriction の仮定下で有効だが crossover が大きい場面で variance が膨張、と既存手法はすべてに limitation がある。**方法**：本研究は lumbar discectomy trial の現実的 parameter（baseline 交絡 構造、crossover rate 10-40%、効果サイズ）を用いた シミュレーション で、(1) ITT、(2) PP、(3) AT、(4) IV、(5) difference-in-differences（DiD）、(6) double negative control（DNC）の6手法を比較。Negative control 系手法（DiD と DNC）は negative control 曝露 と negative control アウトカム を用いて 未測定 交絡 を除去する新しいアプローチで、surgical RCT への適用は本論文が pioneer。各手法の バイアス、MSE、coverage probability を crossover rate を 10%・20%・30%・40% と変化させて評価。**結果**：DNC は crossover rate の全範囲で最小 バイアス と near-nominal coverage を達成し、他の5手法を outperform。特に n=100・crossover rate 40% の challenging な setting でも、DNC は IV 対比 MSE を 90% 以上削減し、coverage probability 97.7% を維持。ITT・PP・AT は crossover が増えるほど バイアス 悪化、IV は variance が膨張し precision が低下。**結論**：surgical RCT における non-compliance 由来 未測定 交絡 への対処として DNC が ITT・PP・AT・IV を全 scenario で outperform。Surgical trial の方法論的厳密性向上に直接寄与する 2026 年 6 月 5 日公刊の最新シミュレーション研究。
▎重要な点
Surgical RCT における non-compliance 由来 未測定 交絡 への対処は、外科治療効果評価の中核的方法論課題で、既存手法（ITT・PP・AT・IV）はすべて限界を持つ。本論文は negative control 系手法（DiD・DNC）を surgical trial に初めて systematic に適用し、DNC が90% MSE 削減と 97.7% coverage を達成することで、surgical RCT の reporting standard を一段引き上げる方法論基盤を提供。本領域の RCT 方法論の進展に直接寄与する 2026 年 6 月 5 日公刊の最新エビデンス。
▎オリジナリティ（独自性）
negative control 系手法（DiD・DNC）を surgical RCT における non-compliance 由来 未測定 交絡 への対処として初めて systematic に評価。Crossover rate 10-40% の全範囲でのシミュレーションと、ITT・PP・AT・IV の4標準手法との直接比較を統合した点が新規。
▎新発見項目（新しく分かったこと）
①lumbar discectomy trial の現実的 parameter を用いた シミュレーション で6手法を比較、
②double negative control（DNC）は crossover rate 10-40% の全範囲で最小 バイアス と near-nominal coverage を達成、
③n=100・crossover rate 40% の challenging な setting で DNC は IV 対比 MSE を 90% 以上削減、
④DNC は coverage probability 97.7% を維持、
⑤ITT・PP・AT は crossover が増えるほど バイアス が悪化、
⑥IV は monotonicity と exclusion restriction の仮定下で有効だが crossover 増加で variance が膨張、
⑦DiD は ITT・PP・AT より頑健だが DNC より バイアス が大きい、
⑧negative control 系手法は negative control 曝露 と negative control アウトカム を用いて 未測定 交絡 を除去する新しい枠組み、
⑨surgical RCT における non-compliance 由来 未測定 交絡 への対処の方法論的進歩、
⑩本論文は surgical RCT の方法論的 reporting standard を一段引き上げる evidence を提供。
▎方法論評価
lumbar discectomy trial の現実的 parameter を用いた シミュレーション で、crossover rate を 10-40% の全範囲で variation。6手法を バイアス、MSE、coverage probability の3指標で評価し、n=100 の small sample でも DNC が他の5手法を outperform することを demonstrate。Surgical trial の典型的 setting への外的妥当性を確保。Limitation として、本研究は シミュレーション ベースで、実 surgical RCT への適用は別途実データでの検証が必要。
▎限界
シミュレーション 研究のため、real surgical RCT での違反の頻度・程度と DNC の performance は別途実データでの検証が必要。lumbar discectomy trial の parameter に依存しているため、他の surgical procedure（例：cardiac surgery、腫瘍外科）への一般化可能性は別途検証。DNC の negative control 曝露・アウトカム の選定には専門知識が必要。本紹介はアブストラクト読解に基づき、本文（BMC OA 全文）の シミュレーション parameter の詳細や追加 感度分析 は本文確認が必要。

Target Trial Emulation of Alcohol Intake Interventions in Young Adults and Risk of CVD over 30 years: Data from the CARDIA study

Li J, Jiang L, Timberlake DS, Wong ND, Jacobs DR, Odegaard AO · European Journal of Preventive Cardiology (IF=7.5), 2026年（June 4 2026） · Target trial emulation。CARDIA study（米国 multi-site coronary artery risk development in young adults コホート、Black and White の 18-30 歳青年期成人をベースライン 1985-1986 から 35 年追跡）を用い、parametric g-formula で time-varying 交絡 と treatment-交絡変数 feedback を処理

▎一言要約
アルコール摂取と心血管疾患（CVD）リスクの関係は長期 観察研究 で u-shape 関連が報告されてきたが、reverse causation、residual 交絡、time-varying treatment-交絡変数 feedback の バイアス への懸念が続いていた。本論文は CARDIA study（米国 multi-site の Black and White 青年期成人 18-30 歳をベースライン 1985-1986 から 35 年追跡）を用いた target trial emulation で、5つの sustained alcohol intake pattern（abstainer、light、moderate、heavy、very heavy）の30年 CVD リスクを parametric g-formula で推定。30年の全体 CVD リスクは 8.7% で、abstaining は slightly lower（8.3%、RD -0.4%、95%CI -0.6 to 0.1）、light（8.8%、RD 0.2%）と moderate（9.4%、RD 0.7%）は minimal な risk 差。Heavy（RD 1.3%）と very heavy（RD 1.9%）は modestly higher だが信頼区間 が 0 を跨ぐ。Abstainer、light、moderate drinkers 間で meaningful な30年 CVD リスク差なしという保守的解釈を、TTE と g-formula で確立した 2026 年 6 月 4 日公刊の最新エビデンス。
▎研究概要
**背景**：alcohol intake と CVD リスクの関連は moderate drinker が abstainer より低リスクを示す u-shape として 観察研究 で長期報告されてきた（French paradox）。しかし、(1) abstainer に sick quitter（健康問題で断酒）が混入する reverse causation、(2) socioeconomic status の residual 交絡、(3) time-varying alcohol intake と time-varying 交絡変数（運動、食事、blood pressure）の feedback による バイアス で causal estimate が歪む懸念が続いている。Mendelian randomization の最新エビデンスは moderate drinking の cardioprotective effect を支持せず、観察研究 の方法論的精緻化が求められていた。**方法**：本論文は CARDIA（Coronary Artery Risk Development in Young Adults）study の Black and White 青年期成人 18-30 歳をベースライン 1985-1986 で登録、35 年追跡した 縦断的 data を用いた target trial emulation。曝露 は self-reported 日次 alcohol 摂取量で性別ごとに 5 categories（abstainer、light、moderate、heavy、very heavy）に分類。Emulated intervention は participants が時間を通じて consistent な alcohol consumption level を維持する仮想シナリオを 5 categories ごとに simulate、long-term CVD risk を推定。Parametric g-formula で time-varying 交絡 と treatment-交絡変数 feedback を処理、複合 CVD アウトカム の30年 incident risk を推定。**結果**：全 participants の30年 CVD リスクは 8.7%。Abstaining は slightly lower risk（8.3%、risk difference [RD] -0.4%、95% CI -0.6 to 0.1）、light drinking（8.8%、RD 0.2%、95% CI -0.1 to 0.2）と moderate drinking（9.4%、RD 0.7%、95% CI -0.1 to 0.9）は minimal な risk 差。Heavy drinking（RD 1.3%、95% CI -0.2 to 1.8）と very heavy drinking（RD 1.9%、95% CI -0.3 to 2.9）は modestly higher risk を示唆するが信頼区間 が 0 を含む。**結論**：本論文は青年期成人の abstainer、light、moderate drinkers 間で 30年 CVD リスクに meaningful な差はなく、heavy alcohol 摂取は modestly higher risk を示唆するが推定が imprecise であるという保守的解釈を提示。Key biases（reverse causation、time-varying 交絡）への対処と長期 縦断的 data を組み合わせることで、臨床・公衆衛生 guidance に資する 2026 年 6 月 4 日 European Journal of Preventive Cardiology 公刊の最新エビデンス。
▎重要な点
アルコール摂取の cardiovascular guidance は 観察研究 の u-shape 関連と Mendelian randomization の null result の間で議論が続いており、本論文は TTE と g-formula で time-varying 交絡 を厳密に処理することで、abstainer・light・moderate drinker 間で meaningful な30年 CVD リスク差なし、heavy drinker は modest だが imprecise な risk 増加、という結論を提示。Cardiovascular prevention の ガイドライン 改訂に直接寄与する 2026 年 6 月 4 日公刊の最新エビデンス。
▎オリジナリティ（独自性）
CARDIA という 35 年追跡 multi-site コホート と TTE+g-formula の組合せで、aging から CVD への30年経路における alcohol intake の causal effect を推定した点が新規。5 sustained intake pattern の hypothetical intervention scenarios を g-formula で simulate し、time-varying 交絡 と treatment-交絡変数 feedback を厳密処理した点が方法論的に独創的。

▎方法論評価
CARDIA study の 35 年 multi-site 縦断的 data と TTE+parametric g-formula の組合せで、time-varying alcohol intake と time-varying 交絡変数（運動、食事、blood pressure、BMI）の feedback を厳密処理。5 sustained intake pattern の hypothetical intervention scenarios を simulate することで、abstainer の sick quitter バイアス と 交絡 を最小化。Limitation として、self-reported alcohol intake の measurement error と sustained intake pattern の hypothetical 性が残る。
▎限界
Self-reported alcohol intake は measurement error が残り、heavy drinkers の under-reporting が known issue。Sustained intake pattern は hypothetical で、real-world では intake pattern が変動するため、解釈は intention に対する効果として扱うのが適切。CARDIA は米国 Black and White 集団に限定されており、他人種・他地域への一般化は別途検証が必要。本紹介はアブストラクト読解に基づき、本文の age stratification、sex stratification、感度分析 の詳細は本文確認が必要。

▎研究への示唆
**PD研究計画 課題1・2への直接適用**：500名コホート で sustained 曝露 pattern（運動・サプリ・食事）と長期 アウトカム（フレイル、認知症）の関連を target trial emulation+parametric g-formula で解析することで、time-varying 交絡 と treatment-交絡変数 feedback を厳密処理できる。Hypothetical intervention scenarios を simulate することで、causal interpretation の robustness を担保。CARDIA に類似する 縦断的 design は TMM や JAGES でも適用可能。
▎研究アイデア
**自前研究・国内大規模データへの応用案**：①TMM コホート で sustained 身体活動 pattern と認知症発症の関連を TTE+parametric g-formula で解析、本論文の CARDIA 結果と Japanese-specific 比較。②JAGES データで介護予防教室への sustained 参加 pattern と要介護化の関連を g-formula で解析し、time-varying 交絡 と treatment-交絡変数 feedback を厳密処理、自治体施策への evidence を提供。③既存900名 コホート で sustained サプリ摂取 pattern と身体機能維持の関連を TTE+g-formula で解析、hypothetical intervention scenarios を 5 categories で simulate、Japanese-specific evidence として国際雑誌に投稿。④学振 PD 課題3 の tDCS+運動の介入研究の解析計画書に parametric g-formula を組み込み、time-varying treatment adherence と 交絡変数 feedback を厳密処理。
