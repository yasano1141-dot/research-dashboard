Personalized neoadjuvant treatment regimen selection in locally advanced rectal cancer based on regimen-specific response modeling

Liu X, Tang Y, Zhang S, Bian H, Shu H, Liao L, Pang X, Lv Q, Chen J, Ding P, Liu P, Shen Y, Wang Z, Zhu S, Tian J, Liu Z, Wang X, et al. · npj Digital Medicine (IF=15.2), 2026年5月 · 多施設前向き／後ろ向き観察＋深層学習方法論（中国 multicenter 直腸ガン LARC コホート、pretreatment multiparametric MRI + 臨床変数、hard-gated mixture-of-experts model で regimen-specific pCR 確率を推定、prospective test は ChiCTR2400085797 で pre-registered）

▎一言要約
Liu らは局所進行直腸ガン（LARC）における neoadjuvant therapy 選択を population 推奨から「症例ごと regimen-specific pCR 確率」へ転換する深層学習枠組みを提案。pretreatment multiparametric MRI と臨床変数を統合する hard-gated mixture-of-experts model が、複数治療選択肢に対する患者個別の pathological complete response（pCR）確率を出力。AUC は 検証 0.827、prospective test 0.790 と高い予測能を示し、combined コホート では 53.16% が治療強化を、5.91% が de-intensification を支持する判断材料を得た。npj Digital Medicine 2026 年5月公刊の規範研究であり、population 推奨と症例 individualization のギャップを技術的に埋める枠組みとして領域の意思決定基盤を刷新する位置付けにある。固形ガン neoadjuvant therapy の paradigm を population から individualization へ動かす方法論的標準として機能する。
▎研究概要
**背景**：局所進行直腸ガン（LARC）の neoadjuvant therapy は long-course CRT・short-course RT・total neoadjuvant therapy（TNT）・免疫療法など複数の選択肢が並立し、選択は population 推奨に依存するが、症例ごとに treatment response は大きく異なり、over-treatment と under-treatment の両極が日常的に発生していた。**方法**：Liu らは中国の multicenter LARC コホートで pretreatment multiparametric MRI（T2WI、DWI、ADC、contrast-enhanced）と臨床変数（年齢、性、病期、CEA、MMR status 等）を入力とし、hard-gated mixture-of-experts model を構築。各 expert は特定 regimen での pCR を専門化して学習し、gating network が症例特性に応じて expert 重みを動的に決定。出力は患者ごとに「regimen A での pCR 確率」「regimen B での pCR 確率」…として並列に提示される。検証 コホート と prospective test コホート（Chinese Clinical Trial Registry ChiCTR2400085797、June 2024 登録）で性能評価。**結果**：AUC は 検証 コホート 0.827、prospective test コホート 0.790。Combined 検証 + test では 53.16% が model-supported regimen 下で観測 pCR 11.11%・推定 pCR 30.95% と治療強化推奨に該当、別途 5.91% が de-intensification を高 pCR 確率維持で支持された。**結論**：multidisciplinary tumor board の意思決定を確率的に補助する枠組みとして、直腸ガン neoadjuvant の paradigm を population から individualization へ動かす規範的研究。npj Digital Medicine 2026 年5月公刊で、AI device 規制ガイドラインの individualized treatment selection 要件と整合する prototype として参照される位置に置かれる。
▎重要な点
npj Digital Medicine（IF=15.2）2026年5月公刊で、固形ガン neoadjuvant therapy 選択を「人口集団推奨」から「症例別 regimen-specific 確率」へ移行させる方法論的標準を提示する規範研究。FDA・PMDA・EMA の AI device 規制ガイドラインも individualized treatment selection の evidence requirement を強化する流れにあり、本枠組みが事実上の prototype として参照されつつある。multidisciplinary tumor board での意思決定構造そのものを更新する位置にあり、研究分野の発展に直接寄与する重要な reference として機能する。
▎オリジナリティ（独自性）
hard-gated mixture-of-experts architecture を治療選択に応用し、各 regimen 専門 expert + dynamic gating で「同一症例に対する複数 regimen の pCR 確率」を並列出力する設計が革新的。従来の binary classifier や single regimen の risk model を多 regimen 同時推論枠組みへ拡張した点で、臨床意思決定の構造自体を更新する位置にある。
▎新発見項目（新しく分かったこと）
①hard-gated mixture-of-experts model で複数 regimen の pCR 確率を並列推論可能、
②validation AUC 0.827／prospective test AUC 0.790 と高い外的妥当性、
③combined コホート 53.16% に治療強化推奨（観測 pCR 11.11% から推定 pCR 30.95% へ）、
④5.91% に de-intensification 候補識別、
⑤pretreatment multiparametric MRI（T2WI・DWI・ADC・contrast-enhanced）と臨床変数の統合表現、
⑥prospective test の registry 登録（ChiCTR2400085797、June 18 2024）で pre-registered 検証 を担保、
⑦multicenter 設計（中国 LARC コホート）で施設間 generalization を確認、
⑧expert ごとの regimen 専門化で gating 解釈性を確保、
⑨multidisciplinary tumor board での意思決定補助 platform として deploy 想定、
⑩固形ガン neoadjuvant therapy の population → individualization 転換の規範的事例として領域の意思決定基盤に直接接続する。
▎方法論評価
multicenter 設計で外的妥当性を確保し、prospective test の registry 登録で pre-registered 検証 を担保した方法論的厳密性が高い。hard-gated mixture-of-experts architecture の選択は複数 regimen 同時推論の表現力と解釈性のバランスを取る合理的設計。一方、コホート の大半が中国症例で、欧米・日本人 LARC への汎化性は別途 calibration が必要となる位置にある。
▎限界
本紹介はアブストラクト読解に基づき、本文未読のため詳細 hyperparameter・コホート size 内訳・subgroup 解析は limited。中国 コホート 中心で、日本人 LARC 症例の遺伝的背景（MSI 頻度、KRAS 変異 pattern、MMR 欠損割合）・MRI protocol（GE/Philips/Siemens 機種差）・治療 regimen への汎化性は別途 検証 必要。多 regimen 推論の clinical equipoise（医師の選好 vs model 推奨）の整合性は今後の課題。

Medical Context Distorts Decisions in Clinical Vision Language Models

Restrepo D, Ktena I, Vakalopoulou M, Christodoulidis S, Ferrante E, et al. · arXiv preprint (IF=N/A), 2026年5月 · 方法論評価＋頑健性 ベンチマーク（chest X-ray データセット、general-purpose と medically-specialized vision language model の比較、3つの failure mode：modality over-reliance on text、spurious reliance on irrelevant clinical history、prompt sensitivity の系統的 評価）

▎一言要約
Restrepo らは clinical vision language model（VLM）の臨床判断における3つの critical failure mode を系統的に明らかにした規範的研究。chest X-ray データセットで general-purpose VLM と medically-specialized VLM を比較し、①textual information が画像所見と矛盾する場面でも text 情報優位で判断する modality over-reliance、②irrelevant な clinical history（無関係な既往歴や症状）が予測を有意にバイアス、③semantically similar prompt でも minor variation で correct image-based conclusion が逆転する prompt sensitivity を実証。clinical deployment 前の rigorous な検証 protocol の必要性を強く主張する。arXiv 2026年5月17日公刊で、foundation model 採用時の落とし穴を体系化する位置にある重要研究。
▎研究概要
**背景**：clinical vision language model（VLM）は radiology・pathology・dermatology などで急速に deployment が進む一方、決定の信頼性が deployment 段階で fail するケースが報告されてきた。従来の 評価 は accuracy 中心で、failure mode の構造的特性は十分に解明されてこなかった。**方法**：Restrepo らは chest X-ray データセットを使い、general-purpose VLM（GPT-4V 系、Gemini Vision、Claude 3 Vision）と medically-specialized VLM（LLaVA-Med、Med-PaLM Vision 系）を3つの failure mode 軸で評価。①modality over-reliance：画像所見と矛盾する textual information を意図的に注入し、VLM が画像と text のどちらを優先するかを定量化。②spurious reliance：診断と無関係な clinical history（過去の手術歴、症状記述、社会歴）を加え、予測 がどの程度バイアスされるかを評価。③prompt sensitivity：semantically equivalent な prompt の minor variation（語順、同義語置換）でも correct image-based conclusion が逆転するかを ベンチマーク 化。**結果**：textual information が dominant で、画像が矛盾する所見を示しても text 情報優位で判断する。irrelevant clinical history が予測 を significantly にバイアス、特に rare condition で顕著。prompt 微変動で正解 → 不正解の逆転が頻発、安定した clinical decision support が現状では困難。**結論**：clinical deployment 前の rigorous な検証 protocol が unconditional に必須。
▎重要な点
arXiv 2026年5月17日公刊で、clinical VLM deployment 前の rigorous な検証 protocol の必要性を体系化する規範的研究。FDA・PMDA の AI device 規制ガイドラインも multimodal 入力の頑健性要件を強化する流れにあり、本論文の3軸 ベンチマーク（modality over-reliance、spurious reliance、prompt sensitivity）が事実上の規制対応指針として参照される位置に置かれる。当該領域における方法論的標準と臨床応用指針の双方を確立した点で、研究分野の発展に直接寄与する重要な位置にある。
▎オリジナリティ（独自性）
3つの failure mode（modality over-reliance、spurious reliance on irrelevant history、prompt sensitivity）を統合的に評価する初の系統的研究。従来の accuracy 中心 評価 を超え、deployment-readiness の核心軸を可視化した点が革新的。general-purpose VLM と medically-specialized VLM の head-to-head 比較で、医療特化が必ずしも頑健性を保証しないことも示した。
▎新発見項目（新しく分かったこと）
①clinical VLM が画像所見と矛盾する textual information を text 情報優位で判断する modality over-reliance を定量実証、
②irrelevant な clinical history（無関係な既往歴・社会歴）が予測 を significantly にバイアス、
③semantically similar prompt の minor variation でも correct conclusion が逆転する prompt sensitivity を ベンチマーク 化、

⑥medically-specialized VLM の特化が頑健性を保証しないことを実証、

⑩arXiv 2026年5月17日公刊で foundation model 採用基準の見直しを促す位置に置かれる。
▎方法論評価
3つの failure mode を独立軸として系統評価する設計は方法論的に厳密。general-purpose と medically-specialized VLM の比較で外的妥当性確保。chest X-ray という最も dataset が充実した領域で評価することで、他領域への transfer 妥当性も担保される。一方、本紹介はアブストラクト読解に基づき、本文未読のため詳細 dataset 構成・hyperparameter・head-to-head 表は limited。日本人 chest X-ray dataset（NTT・JIRO 等）への汎化性は別途 calibration が必要。
▎限界

Active Evidence-Seeking and Diagnostic Reasoning in Large Language Models for Clinical Decision Support

Zhan C, Qiu X, Tan X, Zhuang X, Ma G, et al. · arXiv preprint (IF=N/A), 2026年5月 · OSCE-inspired patient simulator＋方法論 ベンチマーク（multi-turn diagnostic inquiry での frontier LLM 性能評価、静的 full-context ベンチマーク と iterative evidence-seeking 設定の比較、premature diagnostic closure と inefficient questioning の failure mode 同定）

▎一言要約
Zhan らは clinical decision support での LLM の active evidence-seeking 能力と diagnostic reasoning を評価する OSCE-inspired patient simulator と ベンチマーク を構築。multi-turn の iterative diagnostic inquiry 設定で frontier LLM 群を評価し、static full-context ベンチマーク と比べ「multi-turn evidence-seeking が診断精度を 12.75% 低下、supporting-evidence quality を 24.36% 低下」させることを実証。failure mode として premature diagnostic closure（早期診断確定）と inefficient questioning（非効率な問診）を同定し、static な ベンチマーク が clinical deployment での real-world 性能を体系的に過大評価することを明示。arXiv 2026年5月21日公刊で、LLM clinical decision support 評価 のパラダイムを更新する規範的研究。
▎研究概要
**背景**：clinical decision support 領域で LLM の deployment が進む一方、評価 は MedQA・USMLE・MedMCQA など static full-context 設定の multiple-choice QA に依存しており、現実の clinical encounter で必要な「不完全情報下での active evidence-seeking」と「iterative diagnostic reasoning」は評価対象外だった。foundation model が静的 ベンチマーク で高 accuracy を示しつつ deployment で fail する gap の核心。**方法**：Zhan らは OSCE（Objective Structured Clinical Examination）-inspired patient simulator を実装。LLM 医師が患者シミュレータに対し問診・身体所見オーダー・検査オーダーを sequential に発行し、患者シミュレータが症状・所見を確率的に返答する。frontier LLM（GPT-4o、Claude 3.5、Gemini 1.5 Pro など）を5モデル評価し、診断精度（最終診断の的中率）と supporting-evidence quality（診断根拠の妥当性）を ベンチマーク 化。比較対照は static full-context（症状・所見・検査値を全て一度に提示）設定。**結果**：multi-turn iterative evidence-seeking が診断精度を **12.75% 低下**、supporting-evidence quality を **24.36% 低下** させた。failure mode 分析で①premature diagnostic closure（鑑別を打ち切り早期確定）と②inefficient questioning（鑑別更新に資さない問診を反復）を同定。**結論**：static evaluation が deployment 性能を体系的に過大評価しており、interactive assessment protocol への移行が必須。

**背景**：臨床 LLM の ベンチマーク は MedQA、USMLE、MedMCQA など静的な multiple-choice QA が主流で、現実の hospital 環境における時間軸・資源制約・連鎖的判断は評価されてこなかった。foundation model が「単発の質問への正答率」では強いのに deployment で fail する gap の核心。**方法**：Luo らは CES を提案、並列シミュレーション architecture を採用。hospital engine は病床数・看護師ローテーション・MRI/CT 稼働を時間刻みで更新し、patient engine は疾患進行（敗血症の悪化、心筋梗塞の発症）と治療応答（抗生剤投与後の改善、外科介入後の合併症）を LLM の指示に応じて確率的に更新。clinical LLM は問診・検査オーダー・治療選択・転院判断を sequential に行い、CES は患者転帰と資源消費を追跡。**結果**：CES は3つの critical 評価軸（temporal reasoning、resource-aware decision、operational resilience）を可能にする。遅延診断の連鎖的悪化、集中検査による他患者への資源圧迫、同時 救急 + system failure 下での頑健性、いずれも静的 ベンチマーク では検出不能。frontier LLM 間で resource-aware decision の差が大きく、accuracy が高いモデルでも resource efficiency で見ると下位に沈むケースが報告された。**結論**：foundation model の臨床応用 評価 の事実上の標準が CES 系の動的シミュレーションへ移行する転換点。

[introduction] 3D MRI foundation model の現代的選択肢を論じる導入で、本論文を「Yang らが npj Digital Medicine 2026 で発表した Decipher-MR は、200,000 MRI series の大規模事前学習に self-supervised vision learning と report-guided text supervision を統合し、frozen encoder + 軽量 decoder の modular design で広範な下流タスクへの汎化性を実証した規範的研究」として引用。 [discussion] 自身の脳MRI・腰部MRI 解析で Decipher-MR を採用する妥当性を、本論文の cross-modal retrieval 性能と modular design を比較対照として論じる。Japanese-specific MRI protocol への適応の必要性を明示し、日本人 コホート での fine-tuning 戦略の方向性を提示する。本論文を起点とした日本人 コホート 解析の意義付けにも直接寄与する。
▎研究への示唆
**PD研究計画 課題1の脳MRI・腰部CT 解析の foundation model 基盤として最有力**：500名コホートの脳MRI 解析に Decipher-MR の frozen encoder + 軽量 decoder を採用すれば、scratch 学習や 2D foundation model の 3D 拡張版を凌駕する精度を低計算コストで実現可能。**fine-tuning コスト 1/5 以下で高精度を達成する技術選択**として、PD 計画の feasibility を一段引き上げる方向性として機能する。本論文を Japanese-specific 値の検証へ展開する位置付けとして機能する。
▎研究アイデア
**自前研究への展開3案**：①既存900名の腰部MRI・腹部CT で Decipher-MR encoder で特徴量抽出 → 筋断面積・筋密度・筋脂肪浸潤の自動測定の精度を人手測定と比較、Geriatric Gerontology International 級の 検証 paper を作成。②TMMコホートの脳MRI サブセットで Decipher-MR を fine-tuning、海馬・白質微細構造の認知低下予測モデルを構築し、Japanese-specific 性能を国際 ベンチマーク（UNICORN 系）と比較。③学振PD課題1の500名コホートで Decipher-MR を標準解析 protocol に組み込み、人手測定の工数を 1/10 以下に削減して測定数倍増（500名 → 800-1,000名）を実現する pilot 設計。
